翻訳のモデル一覧にはローカルとホスト型の両方が表示されます。選択にはプロバイダー、モデル ID、必要に応じた量子化、画像入力設定が含まれます。

## 接続先

| 種類           | プロバイダー                                                             |
| -------------- | ------------------------------------------------------------------------ |
| ローカル推論   | llama.cpp による GGUF                                                    |
| ホスト型モデル | OpenAI、Gemini、Claude、Grok、MiniMax、DeepSeek、OpenRouter |
| 互換サーバー   | LM Studio、OpenAI 互換エンドポイント                                     |
| 機械翻訳       | DeepL、Google Cloud Translation、Caiyun                                  |
| コマンド連携   | Koharu サーバー経由で応答する外部コマンド                                 |

既定エンドポイント、リクエスト変換、モデル探索は各プロバイダーが担当します。利用可能なモデルは、このドキュメントとは独立して変わります。

<Steps>
  <Step title='接続を保存する'>
    **設定 →
    プロバイダー**で対象を選び、必要な項目を入力します。ホスト型には資格情報が必要です。ローカル互換サーバーにはベース
    URL が必要で、LM Studio の既定は `http://localhost:1234`、OpenAI 互換の既定は
    `http://localhost:11434/v1` です。秘密情報の要否はサーバーの設定によります。
  </Step>
  <Step title='モデルを選ぶ'>
    処理セレクターまたは**設定 →
    翻訳**を開きます。処理セレクターや設定画面を開くとプロバイダーの探索が更新されます。接続できない場合、設定は残っていてもモデルが表示されないことがあります。
  </Step>
  <Step title='ページ画像を含めるか選ぶ'>
    **ビジョン**は既定で有効で、どのモデルでもスイッチを切り替えられます。選択したモデルが画像を受け付けない場合、Koharu
    はリクエストから画像を除外します。OpenAI
    互換エンドポイントは画像を受け付ける前提のため、サーバーが画像メッセージを扱えない場合はスイッチを無効にしてください。
  </Step>
  <Step title='1 ページで試す'>
    原文 OCR を確認し、現在のページを翻訳して応答を確認してから、章全体へ進みます。
  </Step>
</Steps>

## 外部コマンド

`command` プロバイダーは、ホスト型 API の代わりに自作のプログラムを実行します。引数ベクトルを設定すると、`{{id}}` と `{{text}}` がチャンクごとに置換されます。ベクトルはシェルを介さず直接実行されるため、置換後のテキストに引用符や改行が含まれていてもコマンドは変わりません。`timeout_secs` は 1 チャンクの上限で、`segments_per_chunk` はプロセス数と、1 ページの失敗で失う作業量のどちらを優先するかを調整します。

コマンド自身が翻訳を返すわけではありません。`{{id}}` に与えられたチャンク id と、ソースセグメント 1 件につき 1 件の回答を、稼働中の Koharu サーバーの `koharu.submit_translations` ツールに送信して応答します。

<Note>
  このプロバイダーには `koharu-rpc` のサーバートランスポートが必要です。デスクトップアプリには応答用
  チャンネルがないため、そこで `command` を選ぶと翻訳の実行時に失敗します。
</Note>

## 資格情報とプライバシー

秘密情報は OS の安全な資格情報サービスに保存します。秘密でないエンドポイント設定は `~/.koharu/config.toml` に保存します。

取得済みのローカルモデルはプロンプトとテキストを端末内で処理します。ホスト型はリクエスト内容を受け取り、各サービスの保存規約が適用されます。検出や OCR がローカルでも、ホスト型翻訳への送信は発生します。

<Warning>
  キーをプロジェクト指示、テキストレイヤー、設定ファイルへ書かず、**設定 →
  プロバイダー**から保存してください。
</Warning>
